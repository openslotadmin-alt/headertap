Moving your header profiles from ModHeader to HeaderTap

ModHeader is no longer available in the Chrome Web Store or Microsoft Edge Add-ons. Both stores removed it in July 2026 after security researchers reported hidden data-collecting code in version 7.0.18 (TechRadar, July 14, 2026). If you relied on it to set headers while developing or testing, HeaderTap does the same job. It has no account, no tracking, and makes no network requests.

HeaderTap is a product of OpenSlot LLC and is not affiliated with ModHeader. "ModHeader" is named here only to explain how to bring your profiles across.

Bring your profiles across

  • If you have a ModHeader export (a .json file, or JSON text you copied), open HeaderTap, click Import, paste the text or choose the file, and click Check.
  • HeaderTap shows how many profiles, headers and filters it found and how many it imported. Anything it couldn't bring across is listed with the reason.
  • Click Add profiles. Imported profiles start turned off. Look them over, then turn each on with its switch.
  • ModHeader share links can't be imported, because HeaderTap never goes online. Use the JSON export instead.

If you have no export, re-create the profiles by hand. The common ones take a minute each: an Authorization header for a staging API, a User-Agent for mobile testing, or Cache-Control: no-cache.

How the two compare

  • Request and response headers: set, append and remove, like ModHeader.
  • URL filters: HeaderTap has domains, Chrome URL filters and regular expressions. ModHeader's URL regexes import as HeaderTap regex filters.
  • Excluding: HeaderTap can leave out whole domains. Excluded URL patterns from ModHeader are listed as not imported, with the reason.
  • Tab, time and resource-type filters: HeaderTap doesn't have these yet. The import report names any rows that used them.
  • Site access: HeaderTap asks for no site at install. You allow sites one at a time, and headers are changed only on requests to those sites.
  • Privacy: HeaderTap collects nothing and sends nothing. The details are in the privacy policy.

Removing old copies

Removing a listing from a store doesn't always remove the extension from browsers that already have it. To check yours, open chrome://extensions (or edge://extensions in Edge) and remove anything you no longer use.
